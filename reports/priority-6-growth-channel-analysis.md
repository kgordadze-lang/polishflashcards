# Priority 6 — Organic-Growth Readiness

**Phase:** 0 (reports-only). No outreach was performed, no account was created, no post was published.

**Critical caveat, applying to every row in this report:** repository evidence establishes only what the product *is* and what assets *exist*. It establishes **nothing** about market demand, channel performance, audience size, or conversion. Every audience-fit and outcome judgement below is an **Assumption requiring validation** or **Requires external web research**. No figure here is a forecast.

Machine-readable twin: `priority-6-growth-options.csv`.

## 1. Cross-cutting readiness

Assets that exist today and can be pointed at any channel:

| Asset | Status | Evidence |
|---|---|---|
| Working, free, no-account product | **Ready** | verified |
| 32 indexable pages with substantive content | **Ready** | SEO audit §1 |
| Genuine privacy position (no analytics or telemetry in app code, no application cookie, no third parties) | **Ready** and unusually differentiating | claim C-015; live hosting path **Requires live-browser verification** |
| Social preview image (1200×630) | **Ready** | `og-image.png` |
| Founder story | **Partially ready** — strongest version is on `/guide/`, not `/` | positioning audit §1 |
| Locked positioning on the homepage | **Not ready** | positioning finding 1 |
| Correction/feedback route | **Not ready** | feedback finding F-1 |
| Any measurement of what works | **Not ready** | measurement §1 |
| Partnership assets (logos, badges, named reviewers) | **Deliberately absent** | partnership readiness |

**Two prerequisites gate almost every channel below.** Sending traffic to a homepage that does not state who it is for (positioning A-1/S-1) wastes the traffic; sending it with no measurement at all (measurement §2) means little is learned. **Search Console is the cheapest partial fix for the second — but only for Google Search.**

> **Attribution reality for every channel below.** The site is statically hosted, the founder has no access to request logs, and there is no analytics. **Arrivals on this site from any non-Google channel are not observable, and no channel's contribution to meaningful-learning completions is attributable today.** Search Console reports Google Search impressions, clicks, queries, indexing, and link discovery — it is **not a referral analytics system** and cannot count Reddit, newsletter, directory, creator, community, or social arrivals. Where a "Measurement" row below names referral data, read it as *destination-side figures reported by that platform, if it reports any* — not as something measurable on this site. A distinct landing path makes future attribution possible but counts nothing today.

## 2. Channel assessments

### 2.1 Search (organic)

| Field | Assessment |
|---|---|
| **Audience fit** | Highest of any channel — matches the locked audience's actual behaviour (people search "how to say X in Polish" at the moment of need) |
| **Likely message** | None needed; the pages *are* the message |
| **Required asset** | High-intent generated pages for everyday-life topics (SEO S-2); stronger homepage title/description (S-1) |
| **Current readiness** | **Partial.** Technical baseline strong; intent coverage incomplete; zero visibility into performance |
| **Risk** | Low. The main risk is thin content if A1/A2 pages are generated indiscriminately — mitigated by generating 5–8 chosen pages, not 37 |
| **Founder effort** | Moderate one-off (generator extension), near-zero ongoing |
| **Measurement** | Search Console: impressions, clicks, queries, indexing — **Requires Search Console access**. This is the one channel Search Console genuinely measures |
| **Maintenance** | Low — pages regenerate from validated data |
| **External research** | **Required** to select intents |

**Recommended first channel.** It compounds, it needs no ongoing founder presence, and it is the only channel where the product's existing content library is already the asset.

### 2.2 Reddit

| Field | Assessment |
|---|---|
| **Audience fit** | High — r/Polska, r/learnpolish, r/poland, r/expats and similar contain exactly the locked audience. **Requires external web research** to confirm current rules and activity |
| **Likely message** | Founder-first, not product-first: "I'm a foreigner doing a master's in Poland; I built the tool I needed; it's free, no account, and it has no analytics or tracking code" |
| **Required asset** | An honest founder post; the About page it links to |
| **Current readiness** | **Partial** — the story exists but the landing page does not reinforce it |
| **Risk** | **Medium-high.** Self-promotion rules are strictly enforced; a mistimed post can produce a lasting negative association. Karma and history requirements are common |
| **Founder effort** | Low per post, but requires genuine prior participation |
| **Measurement** | Reddit-side post metrics only (views, upvotes, comments). **Arrivals and completions on this site are not observable** |
| **Maintenance** | Ongoing — comment replies are expected, and abandoning a thread reads badly |
| **External research** | **Required** — per-subreddit rules |

**Note:** the product's privacy position and "genuinely free, no account" are unusually well-suited to Reddit's scepticism. The credible version of this post leads with the founder and the constraints, not with features.

## 4. Sequencing recommendation

1. **Before any outreach:** fix the homepage positioning (Phase 1) and add the correction route (Phase 4). Traffic sent to a page that does not state who it is for is wasted, and traffic that finds an error with no way to report it is worse than none.
2. **Configure Search Console** (separate decision) so that at least the search channel becomes observable. Note this makes *Google Search* observable, not the other eleven channels — those remain unmeasurable until an approved measurement mechanism exists.
3. **Then** Search (Phase 3 page generation) and community participation in parallel.
4. **Only after** the above show something: consider creators, teachers, and institutions — all of which carry wording risk and should wait until the claims register is cleaned up in Phase 1.
